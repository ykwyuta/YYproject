# Linux／WindowsのWeb UI

`yyproject` 実行ファイルにWeb UIを内蔵しています。配信用のNode.js、フロントエンドのビルド、別のWebサーバーは不要です。ブラウザーから、WindowsネイティブGUIと同じStoreとデータベースを操作します。MCPは同じポートの `/mcp` で併用できます。

## パスワードの発行と起動

```sh
./yyproject --generate-password alice --auth-config yyproject-server.toml
./yyproject --generate-password viewer --auth-config yyproject-server.toml --read-only
./yyproject --web projects.sqlite3 --listen 127.0.0.1:8740 --auth-config yyproject-server.toml
```

表示された `password` を保存し、ブラウザーで `http://127.0.0.1:8740/` を開きます。ログインはパスワードだけで行い、そのパスワードに対応するユーザー名を画面と監査に使用します。OS乱数256bitの `yyw_` で始まるパスワードを発行し、設定ファイルにはSHA-256ハッシュだけを保存します。任意の短いパスワードを設定するコマンドではありません。

同じユーザー名に再発行するとパスワードが更新され、古いパスワードとそのWebセッションは次の要求から無効になります。平文の再表示機能はありません。読み取り専用ユーザーへの再発行には、再度 `--read-only` を付けます。ユーザーの削除は設定の該当 `[[web_users]]` を削除します。変更は要求ごとに読み込まれます。

PATは従来どおり `--generate-pat USER` で発行します。WebパスワードとPATは別の認証情報で、一方をもう一方のログインに使用できません。同じ設定ファイルに両方を保存できます。

```toml
[server]
allowed_hosts = ["projects.example.com"]
allowed_origins = ["https://projects.example.com"]
secure_cookies = true

[[web_users]]
name = "alice"
password_sha256 = "発行コマンドが保存した64文字のハッシュ"
read_only = false
```

このハッシュ例は説明用です。実際の設定はコマンドで生成してください。Webユーザーだけの設定も使用できます。

外部へ公開する場合はHTTPSのリバースプロキシを前段に置き、`Host` を保持します。`allowed_hosts` とHTTPSの `allowed_origins` を設定し、`secure_cookies = true` にします。直接HTTPで使用するローカル環境の既定値はfalseです。ループバック以外へ待ち受ける場合、許可Hostの明示が必要です。待ち受け・許可Host/Origin・Secure設定の変更はサーバーを再起動します。

セッションはHttpOnly／SameSite=StrictのCookieで管理し、無通信30分・最長12時間で終了します。更新APIはOriginとCSRFトークンを検証します。認証情報をLocal Storageに保存しません。画面の寸法・最後に開いた画面と案件IDだけをブラウザーに保存します。

## PostgreSQLモード

```sh
export YYPROJECT_DATABASE_URL='postgresql://USER:PASSWORD@HOST:PORT/DATABASE?sslmode=disable'
./yyproject --web-postgres --listen 127.0.0.1:8740 --auth-config yyproject-server.toml
```

Docker ComposeでのDB起動・接続・双方向移行は[PostgreSQLガイド](postgresql.md)を参照してください。`--web`／`--web-postgres` に `--read-only` を付けると全ユーザーが参照専用になります。データベースの接続先変更と移行はサーバーの管理コマンドで行います。

## グリッドの操作

タスク・バグ・課題・依頼／質問・暫定対応の各一覧とマスタは、共通のグリッド操作を提供します。

|操作|手順|
|---|---|
|セル編集|セルを選択しF2／Enter／ダブルクリック。Enterで確定、Shift+Enterで改行、Escで取り消し、Tabで次の列へ|
|範囲選択|セルからドラッグ、Shift+クリック、Shift+矢印。Ctrl+Aで表示範囲全体|
|行選択|行チェックボックス、Ctrl+クリック、Shiftによる連続範囲|
|コピー・貼り付け|Ctrl+C／Ctrl+V、またはツールバー。引用符・タブ・改行を含むTSVに対応|
|同列コピー|属性列の2行以上を選択しCtrl+D／下方向にコピー|
|一括編集|行を選択し「一括編集」。属性ごとに変更しない／設定／空欄を指定|
|行移動|タスク系の一覧でIDセルをドラッグして移動先の行にドロップ。タスクの子孫も既存ルールで移動|
|寸法変更|列境界をドラッグして幅、IDセル下の行境界をドラッグして高さを変更。Escで取り消し|
|列値の絞り込み|列の見出しを右クリックし値を選択。列単位の解除と条件入力も可能|
|全文検索|検索欄に入力してEnter。Ctrl+Fで検索欄へ移動|
|子タスク|タスク一覧の行を右クリックして追加。子・孫タスクの検証はネイティブGUIと共通|

件名、本文、対策内容など個別項目は一括上書き対象にしません。不正な貼り付けや一括変更は全体が取り消されます。大きな一覧は表示領域付近の行だけを描画し、選択・コピー・更新は元の行IDで処理します。

ブラウザーのClipboard APIが使えないHTTP接続や権限設定でも、グリッドにフォーカスしてCtrl+C/Vを使用できます。貼り付けボタンで許可されない場合は入力ダイアログを表示します。

## 各画面と保存

カンバンはカードを状態列へドラッグします。移動中はブラウザーのドラッグ画像がカーソルに追従し、移動先の列を強調します。完了・再開の検証、残作業の進捗入力は既存ルールを使用します。

ガントは年／月／日／曜日の4段表示、休日背景、マイルストーン、太い稲妻線を表示します。「表示・統計設定」で起点・日幅・稲妻の基準日を選びます。項目・予定日程の境界と行境界をドラッグして寸法を変えられます。日程バーのドラッグで日付を移動でき、Esc／キャプチャ喪失で取り消します。マイルストーン登録時は同日・工数0・期間0に設定します。

バーンダウン／バーンアップと各種統計は、日次格子・休日色・週ごとの日付と曜日／日／月／年、太い線を使用します。依存ネットワークの項目を選ぶと、その先行・後続系統を強調し、その他を薄くします。マスタのカテゴリ・担当者・休日はタブで排他的に表示します。

依頼のやりとりは「やりとり記録」から手入力し、編集・削除できます。送受信・通知・添付はありません。CSVは条件と列を選択でき、Jira用CSVは課題タイプも設定できます。「SQLiteへ書き出し」は、監査を含む全案件のバックアップをブラウザーにダウンロードします。認証設定ファイルは含みません。

MCP・ネイティブGUIと同じ版競合検出・監査・トランザクションを使用します。MCPなど他の操作による更新は、セルやダイアログを編集中でないときに定期反映します。編集中に他から更新された場合は上書きせず、入力を保持して競合を表示します。内容を確認し、必要な入力を控えてからEsc・再読込・再編集してください。

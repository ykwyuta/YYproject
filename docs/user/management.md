# 他チームへの依頼・質問と暫定対応

「編集 → 依頼・質問を追加」「編集 → 暫定対応を追加」で登録します。タスク・バグ・課題と別の一覧、別の統計で管理し、担当者・カテゴリ・優先度・状態・説明・対応タスクIDを付けられます。工数チャートには算入しません。

## 依頼・質問とやりとりの記録

種別（依頼／質問）、相手チーム、相手担当者、依頼・質問日時、回答期限、回答日時、完了・中止日時を入力します。相手チームは必須です。回答済みでも調整が残れば「進行中」にし、終了したら「完了」にします。「中止」は完了件数と分けて集計します。

依頼・質問一覧で行を選び、右クリックの「やりとりを記録」から日時、方向（こちらから／相手から／メモ）、相手・記録者、複数行の内容を手入力します。同じメニューで記録の確認・編集・削除ができます。「編集」メニューからも操作できます。記録には連番が付き、削除後も番号は再利用せず、変更・削除の監査を保持します。行の通常編集や一括変更で記録が消えることはありません。

送受信、通知、メール連携、添付はありません。別の手段で行ったやりとりの経過と、次に回答が必要な案件を管理する機能です。

## 暫定対応

発生理由（必須）、恒久対応のために必要なもの、実施した暫定対応内容、暫定対応の分類、検知日時、暫定対応日時、恒久対応日時、恒久対応の実施予定日を記録します。暫定対応日時を入れる場合は実施内容も必要です。暫定対応を実施しても、恒久対応待ちの間は「進行中」などにし、恒久対応が完了したら「完了」にします。

完了日時は未入力なら保存時に補完します。中止の場合は中止日時を内部に記録し、恒久対応を実施したことにはしません。再開すると現在の完了日時をクリアしますが、完了・中止・再開の状態履歴は残ります。

日時は `2026-10-27T09:00:00+09:00` のようにタイムゾーンを付け、予定日は `2026-10-30` とします。保存と日別集計はUTCです。依頼・検知より前の回答・実施・記録日時や、暫定対応より前の恒久対応日時は拒否します。

## 一覧・検索・CSV

一覧はタスク一覧と共通の操作です。セルを選択してF2で編集、Ctrl+C/Vでコピー・貼り付け、属性列の範囲を選択してCtrl+Dで先頭行を下へコピーします。Shift／Ctrlで複数行を選択して「選択行の属性を一括変更」を使えます。件名・発生理由・実施内容・やりとり本文は個別編集です。

列境界で列幅、行境界で行高をドラッグして変更します。ID列をドラッグすると行を移動できます。列の見出しを右クリックして列値で絞り込み、Ctrl+Fで本文や相手チーム、やりとり内容も検索できます。

「ファイル → 依頼・質問一覧をCSV出力／暫定対応一覧をCSV出力」で条件と出力列を選べます。現在の列フィルターも適用します。依頼の「やりとり記録」は日時・方向・記録者・本文を複数行で含みます。CSVはUTF-8 BOM付きで、引用符・カンマ・改行を保持します。

## 統計

「依頼・質問統計」「暫定対応統計」は日ごとの未完了件数、完了・中止・再開を状態履歴から集計します。タスクのバーンダウンと同じ日次格子、休日背景、曜日／日／月／年、太い線を使用します。「統計設定」で集計期間を指定します。対象は現在の絞り込み、分類・担当者は現在値、件数は終了日UTCの日末時点です。終了日より前の日付の未完了期限を期限超過とします。

依頼では相手チーム・依頼／質問・状態の件数と割合、未回答、期限超過、平均回答時間、期間内の方向別記録数を表示します。暫定対応では分類・状態、暫定未実施、恒久予定超過、平均暫定対応時間・恒久対応時間を表示します。算出できない平均値は「未算出」です。

## MCP

stdio・PAT認証のStreamable HTTPで同じ操作を使えます。

|操作|ツール／変更|
|---|---|
|登録・編集・同列値のコピー・一括更新|`project_change` の `save_task`／`save_tasks`、`task.inquiry`／`task.workaround`|
|記録の追加・編集|`save_exchange`（依頼の `id` と `entry`。新規の `entry.id` は0、省略可）|
|記録の削除|`remove_exchange`（依頼の `id` と `entry_id`）|
|一覧・全文検索・列値条件|`task_list` の `kind: inquiry/workaround`、`query`、`columns`|
|行順・保管・復元|`move_task`／`remove_task`／`restore_task`|
|日次収束・分類と期限統計|`management_statistics` の `project_id, kind, from, to, filter`|
|選択列・条件付きCSV|`csv_export` の `project_id, columns, filter`。返された `content` をクライアントで保存|

更新は最新の `expected_revision` を指定します。記録と状態履歴はサーバーが管理します。読み取り専用PATでは一覧・統計・CSVを利用できます。CSV出力はサーバーの任意パスへの保存を行いません。Jira専用CSVはタスク・バグ・課題を種類で絞ってGUIから出力します。依頼・暫定対応は標準CSVを使用します。DB移行はGUI／CLI、列幅などの画面設定はGUIで操作します。

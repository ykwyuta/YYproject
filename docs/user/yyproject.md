# yyproject

タスク・課題・進捗を管理します。Windows GUIは `yyprojectw`、AI向けMCPサーバーは `yyproject` です。MCPはWindowsとLinuxに対応します。SQLiteは同梱しており、外部DBサーバーは不要です。

## 起動

```powershell
yyprojectw C:\projects\team.sqlite3
yyproject --init-demo C:\projects\sample.sqlite3
yyprojectw C:\projects\sample.sqlite3
```

ファイル未指定の場合、GUIは `%LOCALAPPDATA%\YYProject\projects.sqlite3` を使用します。ファイル → プロジェクトを追加で名前・開始日・完了予定日を登録します。1つのDBに複数プロジェクトを保存し、画面上部で切り替えます。

## 表示と編集

| 表示 | 用途 |
| --- | --- |
| カンバン | 未着手・進行中・保留・完了・中止の列へ項目を表示。カードのドラッグで状態を変更 |
| ガント | 開始日・期限・進捗を表示。土日と休日マスタの休日を区別 |
| タスク一覧／課題一覧 | 件名・状態・担当者・カテゴリ・日程・工数・進捗を表で確認 |
| 依存ネットワーク | 先行項目から後続項目への矢印を表示 |
| バーンダウン | 記録した残工数の推移 |
| バーンアップ | 完了工数と総工数の推移 |
| マスタ | カテゴリ・担当者・休日の登録内容 |

編集メニューで項目・マスタ・依存関係を追加します。項目を選んで編集、またはダブルクリックします。タスクの編集画面は基本情報・日程と進捗・説明を切り替えて入力します。担当者とカテゴリはマスタから選択します。期間は営業日（0は1営業日として計算）、工数は時間、進捗は0～100%です。完了状態では100%になります。中止した項目はチャートの集計から除外します。

依存関係には待機営業日を設定できます。「営業日で日程を再計算」は、各項目の開始指定と先行項目の期限を考慮し、土日・休日を除いて日程を更新します。循環した依存関係は登録できません。担当者のリソース平準化は行いません。

幅が狭い場合、表示タブは横にスクロールします。表示メニューからも画面を切り替えられます。ホイールは縦、Shift＋ホイールは横に移動します。スクロールバーも使用できます。

## 保存とAIの連携

変更は即座にSQLiteへ保存します。同じホスト上のMCPとGUIがローカルディスク上の同じDBを開く場合、プロジェクト版の競合を検出して上書きを拒否します。別プロセスでの変更はGUIへ再読み込みします。LinuxのMCPは独立して利用でき、Windows GUIとの遠隔DB共有サービスは提供しません。ネットワーク共有フォルダをDBの保存先にしないでください。進捗はローカル日付ごとに記録し、同日の最新状態を使います。過去の記録は後日の変更で置き換えません。

ファイル → プロジェクトをJSON出力で、項目・マスタ・依存関係・進捗記録を出力できます。これはDB全体と監査ログのバックアップではありません。WAL使用中のDBをバックアップするときはアプリとMCPサーバーを終了してからSQLiteファイルをコピーしてください。

[同梱ヘルプ・MCP設定と操作スキーマ](../../help/help.md)を参照してください。GUIのヘルプは既存YYシリーズと共通のMarkdownビューアーを使い、WebView2がない場合はテキスト表示へ切り替わります。

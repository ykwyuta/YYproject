# v0.2.0 リリース検証（2026-10-27）

ワークスペースとWindowsアセンブリの版を0.2.0へ更新した。利用中の `demo/yyproject-demo.sqlite3` はコミット対象に含めず、Git管理版のデモDBを使う検証用ソースコピーでローカル試験を実行した。

5624d143c0276d55f31bf2b29ae32a2466c48906のCIではLinuxとPostgreSQLのジョブが成功した。Windowsはfmt・Clippy・全テスト・リリースビルド・実stdio MCP・HTTP/PATまで成功したが、GUI試験が失敗した。

GUIの失敗時はDPI96、表示領域の高さ301、コンテンツの高さ290であり、スクロール不要な状態で縦スクロールを待っていた。自動スクロール試験の前に実際のコンテンツとクライアント領域からウィンドウの高さを調整し、表示領域からコンテンツがはみ出した状態を期限付きで確認するよう修正した。スクロール後の座標・保存・キャンセルの検証は維持している。固定sleepや試験の除外は追加していない。

修正後のローカルWindowsではfmt・Clippy（警告をエラー扱い）・全28テスト・リリースビルド・専用DBと所有ウィンドウを使うGUI試験が成功した。実DPI192で確認し、所有プロセスは期限60秒で終了を確認・回収した。DPI96での修正結果と最終SHAの全ジョブ成功は、再実行したCIの完了結果で判定する。

# v0.3.0 リリース準備（2026-10-27）

v0.2.0以降のバグ・課題管理、他チームへの依頼・質問と手動のやりとり記録、暫定対応管理、専用一覧・統計・CSV、MCP操作を含む機能リリース。Cargoワークスペース、Cargo.lockの自パッケージ、Windowsマニフェストを0.3.0へ更新する。Git依存のSHAと第三者ライセンスは変更しない。

版更新後のローカルWindowsでfmt、全workspace/all-targetsのClippy（警告をエラー扱い）、Rust試験35件、リリースビルドが成功した。利用者の変更済みデモDBはコミット対象から外し、HEADの基本デモと拡充デモを使って検証する。機能と操作性の評価は[管理機能の記録](yyproject-management-2026-10-27.md)、[バグ・課題の記録](yyproject-cases-2026-10-27.md)を参照。

公開時は、プッシュした最新SHAのWindows、Linux、PostgreSQLのCI全ジョブが完了・成功したことを確認する。Windowsジョブの実GUI試験はLinux成功で代用しない。公開物には当該CIから取得したWindows ZIPとLinux tar.gzを使用し、内容、ライセンス・ヘルプ・デモ、実行ファイルの版、SHA-256を確認する。タグは同じSHAを指すものとし、公開先はGitHub Releasesのv0.3.0とする。公開完了とCIの具体的なURLはリリースノートに記録する。

保存形式は6。形式1〜5のSQLite、形式3〜5のPostgreSQLを読み込み、成功した書き込みで移行する。旧版は形式6のDBを開けないため、更新前のDBを残す。依頼・暫定対応は工数集計から除外する。Jira専用CSVはタスク・バグ・課題、管理記録は標準CSVを使用する。送受信・通知・添付は提供しない。

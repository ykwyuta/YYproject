# Web版に合わせたWindows版デザイン（2026-10-27）

Web UIと同じ濃紺ナビゲーション、白い案件ヘッダー、淡い背景、青い選択色・主要ボタン、薄い罫線をWindowsネイティブGUIへ適用した。一覧・マスタ・ガント・ネットワーク・統計の配色を揃え、Yu Gothic UIの14px相当をDPIに応じて使用する。カードは白地・枠・状態色のアクセント、ガントは初期52px行高で件名と日程を別行にした。

左側の15画面ナビゲーションとツールバーはWin32の実ボタンで、名前、クリック、Space、フォーカス枠を持つ。追加は画面の種類に対応する。既存メニューとショートカットを保持する。狭い／低いクライアント領域では画面選択ComboBoxに切り替え、一行に収まらない操作はメニューから使用する。F6でナビゲーションへフォーカスを移し、コントロール間のTab移動を使う。表内のTabは従来どおり次の列へ移動する。

## 検証

- Windows: fmt、全workspace/all-targets Clippy（警告エラー）、Rust 36件、releaseビルド成功。
- Linux: Dockerでfmt／Clippy、Rust 35件、実stdio MCP成功。Windows専用の描画変更として区別する。
- Windows release `yyprojectw --ui-smoke-test NEW_DIRECTORY`: 専用DB・所有プロセスで全試験が成功し終了コード0。実DPIは192（200%）。[実状態ログ](evidence/yyproject-native-web-design.txt)。
- 新規ナビゲーション: 左ボタンの実BM_CLICKとコンパクト選択欄の変更通知で全15画面へ移動。可視コントロールの実矩形がクライアント領域内に収まり、一覧領域が確保されることを期限付きで検証した。
- 既存回帰: セル編集・複数行／複数列コピーと貼り付け・同列コピー・一括属性編集・行／カードドラッグ・スクロール・列幅／行高・Esc取消・ヘッダーフィルター・子孫階層・CSV／Jira・各種類フォーム・統計が成功。
- Windows releaseでも実stdio MCPとPAT HTTPを確認。stdioの同梱デモ試験は利用者の変更済みDBを参照すると件数差が出るため、Gitの配布用DBを使った分離ソースで実行して成功した。利用者DBは変更しない。

最初の実DPI試験で狭い領域にツールバーが収まらない点を修正し、コンパクト表示を追加した。左ナビ追加に伴い、旧試験の固定X座標2箇所を現在のbody.leftとスクロールから求めるよう修正した。ガント行高の検証は新しい初期52pxから20px増加した72pxを確認する。検証除外や警告のallowは追加していない。

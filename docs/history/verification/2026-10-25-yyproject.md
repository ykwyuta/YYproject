# yyproject 初期実装の検証記録

2026-10-25。対象は `a5c7fa2a43ec6ff531426610133688ff3875d3ff` からの未コミット変更。現行の操作は[利用者ガイド](../../user/yyproject.md)、構成は[開発者向け文書](../../developer/yyproject.md)を参照。

## 実行した検証

- Windows x64、Rust 1.99.0 MSVC：独立ワークスペースのfmt、全ターゲットClippy（警告をエラー扱い）、SQLiteモデルの6試験、MCPの2試験、リリースビルドが成功。
- Linux x64、Rust 1.99.0／Debian bookwormのDocker：独立ワークスペースのfmt、全ターゲットClippy、同じ8試験、ビルド、実プロセスのstdio MCP通信が成功。
- ルートワークスペース：Windows／Linuxでfmtと全ターゲットClippyが成功。共有ライブラリ本体の変更はない。既存アプリ全体のGUI試験は今回実行していない。
- 実プロセスのMCP検証：初期化、ツール発見、日本語タスクの永続化、古い版による更新の拒否、操作主体を含む監査記録、読み取り専用での更新拒否。Windowsではリリースバイナリでも成功。
- WindowsリリースバイナリのネイティブUI検証：8画面を1100×700／640×480で描画。実環境のDPIは192。実際のクライアント領域から表示範囲とヒット位置を計算した。ガントの横・縦スクロールも描画した。
- 実際の入力コントロールでタスク・マスタを作成・編集し、別のSQLite接続からの変更の再読込、説明文の改行とマスタ参照の保持、複数プロジェクト間の切り替え、カンバンドラッグ後の状態と進捗の永続化を確認。

モデル試験では、休日・週末・待機営業日、営業日計算と逐日計算の一致、依存の循環・不明ID・重複の拒否、参照中マスタ削除のロールバック、IDの非再利用、過去の進捗記録の保持、他アプリのSQLiteファイルと不正値の拒否を検証した。

## 検証中に修正した不具合

- 空欄セルをDrawTextWへ渡す際のゼロ長バッファによるUSER32のアクセス違反。空文字と無効な矩形を描画しないようにし、UTF-16バッファを終端した。
- 高DPIの狭い画面で複数行タブが内容を隠す問題。横スクロールする1行のタブに変更。
- プロジェクト切り替え時に別プロジェクトの依存ネットワークのキャッシュが残る問題。モデル再読込と一緒に再構築。
- ガントのスクロール時にバーが固定の項目名・見出しへ重なる問題。日程領域、バー領域、項目名の描画範囲を分けた。
- PythonのSQLite接続がWindowsの一時DB削除まで残る問題。接続を明示的に閉じるよう修正。

## 検証範囲の限界

GitHub CIにはWindows／Linuxの検査・リリースビルド・MCP・Windows UI試験を追加したが、この変更のGitHub CIはまだ実行していない。ローカルの成功と区別する。Linux GUIは提供しない。ネットワーク共有上のDBや異なるOS間の直接DB共有は対象外。担当者負荷の平準化とクリティカルパス解析は実装していない。

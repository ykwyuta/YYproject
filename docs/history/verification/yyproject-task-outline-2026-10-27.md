# 親子タスクの階層表示と折りたたみ（2026-10-27）

Windows版とWeb版のタスク一覧・ガントで、親行に▼／▶を表示し、子・孫を折りたためるようにした。インデント・接続線・親ID・子件数で所属を示す。Ctrl+Spaceでも切り替えられる。親を閉じても子の開閉状態を保持し、新しい子の追加時は直接の親を開く。

表示用の射影はcore/table::outline_rowsで、祖先がフィルター結果に存在する場合だけその折りたたみを子孫へ適用する。親が検索条件に一致しない場合も、一致する子を隠さない。Windowsのグリッド行・ガント描画・高さ・ヒット領域・行高変更で同じ可視行を使う。Webも同じ条件で可視行を計算する。ガントの稲妻線は可視行へ再配置する。

開閉は表示だけで、Storeへの書き込み、版更新、監査追加を行わない。隠れる行を含む選択は解除し、コピー・貼り付け・一括編集は可視行の生の値を使う。件名にアイコン等の表示文字を保存しない。CSVは従来どおりTaskFilterで出力し、折りたたみを適用しない。ネイティブは実行中に案件別の状態を保持し、DB接続変更時に破棄する。Webは案件別にLocal Storageへ保存する。

共通試験は親・子・孫と別系統を作り、開閉・入れ子の保持・検索・保存結果と監査が変わらないことを確認した。Windows専用試験は実DPI192の専用ウィンドウで、一覧とガントのアイコンの実ヒット領域をクリックし、子孫の表示と選択解除を検証した。既存のコピー・編集・一括編集・ドラッグ・寸法変更・各種類の管理画面も回帰試験が成功した。所有プロセスを期限付きで終了確認した。

ブラウザー試験は従来17操作に、親子・孫の実クリック／Ctrl+Space、一覧とガント間の状態共有、隠れた子をコピーしないこと、リロード後の状態保持、親が条件外の場合の孫の検索、開閉によるプロジェクト更新がないことを追加した。範囲全選択後はフォーカスが末行へ移るため、Ctrl+Space試験は親の件名を再選択してから行う。

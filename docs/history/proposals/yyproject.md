# yyproject

Rustで実装するWindows向けプロジェクト管理GUIと、Windows／Linux向けstdio MCPサーバーを追加する。SQLiteを同梱し、タスク・課題・担当者・カテゴリ・休日・依存関係・進捗履歴を管理する。

GUIはカンバン、ガント、タスク／課題一覧、依存ネットワーク、バーンダウン／バーンアップ、マスタ管理を同じデータから表示する。既存YYのフォント、ネイティブUI、アイコン生成・埋め込み、Markdownヘルプを流用する。MCPは同じRustコアを使い、任意SQLを受け付けない。

SQLiteのトランザクションとプロジェクト版番号によりGUIとAIの更新競合を検出する。依存関係は循環・プロジェクト外参照を拒否する。日程再計算では土日と休日マスタを考慮する。チャートは現在値から過去を捏造せず、記録した日付ごとの進捗を使う。変更履歴には操作主体・時刻・操作を記録する。

独立Cargoワークスペースとして同じリポジトリに置き、既存CIにWindows／Linuxの検査・試験・配布資材を追加する。Windows GUIとLinux MCPの検証を区別する。
